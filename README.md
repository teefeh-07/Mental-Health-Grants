# Mental Health Grants DAO 🧠✨

## Mission 🚀
Empowering decentralized, transparent, and community-driven funding for mental health initiatives globally.

## 🛠️ Technical Stack
- **Smart Contracts:** Clarity 4.0 (Epoch 3.3)
- **Frontend:** React + TypeScript + Vite
- **Blockchain:** Stacks L2
- **Connectivity:** @stacks/connect, @stacks/transactions
- **Indexing:** Hiro Chainhooks
